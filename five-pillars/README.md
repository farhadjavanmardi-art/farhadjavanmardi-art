# پنج ستون (5P)

تحلیل هر نوع کسب‌وکار در پنج ستون، با Claude API:

1. **امکان‌سنجی**: آیا شدنی است و با چه شرطی
2. **بیزینس پلن**: تصویر یکپارچه برای مالک، شریک یا سرمایه‌گذار
3. **بازاریابی**: جذب مشتری با هزینه‌ی قابل تحمل
4. **عملیات**: کارهای روزانه، استانداردها، چک‌لیست‌ها
5. **مالی**: مدل ۳۶ ماهه، سربه‌سر، بازگشت سرمایه، سناریوها

در پایان، اپ یک **حکم** (اجرا / اجرا با شرط / مانع) و یک **برنامه‌ی پیشرفت** ۳۰، ۶۰ و ۹۰ روزه و ۱۲ ماهه می‌دهد.

## چطور کار می‌کند

- کاربر نوع کسب‌وکار را انتخاب می‌کند (کافه، رستوران، آرایشگاه، فروشگاه، آموزشگاه، اقامتگاه، خدمات، سرویس آنلاین، تولیدی یا سایر). فرم با اعداد معمول همان کسب‌وکار پر می‌شود و کاربر فقط عددهای خودش را جایگزین می‌کند.
- **همه‌ی اعداد را موتور مالی (کد) حساب می‌کند**، نه Claude. ترازنامه و جمع ماه‌ها خودکار چک می‌شوند.
- Claude فقط متن‌ها را می‌نویسد و با قوانین سخت‌گیرانه کار می‌کند: عدد ساختگی، تحقیق ساختگی یا ابزاری که در کشور کاربر کار نمی‌کند، ممنوع است. هر عددی که در متن بیاید و در موتور نباشد، خودکار علامت می‌خورد.
- بعد از هر ستون، Claude آن را بازبینی می‌کند و امتیاز می‌دهد.

## اجرا

نیاز: Node.js نسخه‌ی ۲۲.۹ یا بالاتر، و یک کلید API از [platform.claude.com](https://platform.claude.com).

```bash
cd five-pillars
npm install
cp .env.example .env      # کلید را در .env بگذارید
npm start
```

بعد در مرورگر باز کنید: http://127.0.0.1:3000

پروژه‌ها در مرورگر همان کاربر ذخیره می‌شوند (localStorage). «دانلود گزارش» یک فایل HTML کامل از هر پنج ستون می‌دهد.

## فایل‌ها

| فایل | کار |
|---|---|
| `app.html` | کل اپ: فرم، موتور مالی، پنج ستون، پرامپت‌ها، حکم و برنامه. همین فایل در claude.ai هم به‌صورت Artifact منتشر شده است. |
| `public/claude-shim.js` | رابط Claude را در مرورگر به سرور خودمان وصل می‌کند و ذخیره را در localStorage انجام می‌دهد. |
| `public/index.html` | از `app.html` ساخته می‌شود: `npm run build:page` |
| `server.js` | صفحه را نشان می‌دهد و درخواست‌ها را به Claude API می‌فرستد. کلید API فقط روی سرور است. |

بعد از هر تغییر در `app.html`، دستور `npm run build:page` را بزنید.

## تنظیمات (`.env`)

| متغیر | پیش‌فرض |
|---|---|
| `ANTHROPIC_API_KEY` | الزامی |
| `CLAUDE_MODEL` | `claude-opus-5-5` |
| `PORT` | `3000` |
| `HOST` | `127.0.0.1` (فقط همین کامپیوتر؛ برای سرور عمومی `0.0.0.0` بگذارید و حتماً ورود کاربر اضافه کنید) |

## هزینه

نوشتن کامل یک پروژه (پنج ستون، بازبینی‌ها و برنامه) حدود ۱۵ درخواست به Claude است. هزینه به حساب API شما نوشته می‌شود.

## محدودیت‌های این نسخه

- ورود کاربر ندارد. اگر روی اینترنت قرار بگیرد، هر کسی می‌تواند با کلید شما درخواست بفرستد.
- پروژه‌ها فقط در همان مرورگر ذخیره می‌شوند.
