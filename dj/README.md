# Javan Decks – برنامه‌ی دی‌جی در مرورگر

یک میکسر دو دکه که فقط با یک فایل (`index.html`) در مرورگر اجرا می‌شود. نصب لازم نیست.

## اجرا
فایل `dj/index.html` را در Chrome، Edge یا Firefox باز کنید. آهنگ‌هایتان را با **Add tracks** اضافه کنید یا مستقیم روی دک A یا B بکشید. دو آهنگ دمو از اول بارگذاری شده‌اند.

## امکانات
- دو دک با PLAY، CUE، ۴ هات‌کیو، لوپ (½ تا ۸ ضرب) و اسلایدر تمپو (±۸ / ±۱۶ / ±۵۰٪)
- تشخیص خودکار BPM و گرید ضرب، دکمه‌ی **SYNC** (سرعت و فاز ضرب)
- میکسر: Trim، اکولایزر سه‌باند با Kill، فیلتر Low/High-pass، فیدر کانال، VU متر
- کراس‌فیدر (Smooth یا Cut) و ولوم مستر با لیمیتر
- موج اسکرول‌شونده با گرید ضرب، کشیدن برای جابه‌جایی
- ضبط کل میکس و دانلود فایل
- میانبرهای کیبورد (با کیبورد فارسی هم کار می‌کند) – راهنمای کامل داخل برنامه، دکمه‌ی **Help · راهنما**

| | دک A | دک B |
|---|---|---|
| پخش/توقف | `Q` | `P` |
| کیو | `W` | `O` |
| سینک | `E` | `I` |
| لوپ ۴ ضرب | `R` | `U` |
| هات‌کیو | `1`–`4` | `7`–`0` |

کراس‌فیدر: `←` `→`، وسط: `↓`

## محدودیت‌ها
- تغییر تمپو مثل صفحه‌ی گرامافون زیر و بمی صدا را هم عوض می‌کند (Key lock ندارد).
- خروجی هدفون جدا (Cue/Pre-listen) ندارد؛ همه‌چیز از خروجی اصلی پخش می‌شود.
- اتصال کنترلر MIDI ندارد.
